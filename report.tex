\begin{abstract}
\onehalfspacing
In many companies, information is scattered across different documents and departments, making it hard for employees to find what they need quickly. During my internship, I worked on OpsMind AI, a tool that solves this problem. It is a web application built with React, Node.js, and MongoDB that lets users search through company documents using natural language. Under the hood, it uses Retrieval-Augmented Generation (RAG) by combining MongoDB Atlas Vector Search with the Gemini API. The system parses PDF documents, breaks them into chunks, and stores their vector embeddings. When a user asks a question, the application streams back a context-aware answer in real-time using Server-Sent Events (SSE). This project helped me learn how to build practical AI features into a full-stack application, ultimately making information retrieval much faster for corporate teams.
\end{abstract}
